## Slide 1: Problem

### Nepal's Digital Payment Gap

**The Challenge:**
- 65% of transactions in Nepal are still cash-based
- 45% of adults lack formal bank accounts
- Average remittance fee: NPR 2,000+ per transfer (3-5%)
- 90% of small merchants cannot accept digital payments
- Rural areas remain financially underserved

**The Human Cost:**
> "I travel 3 hours to pay my electricity bill. There is no digital option in my village."
> — Rural resident, Province 2

**Market Pain:**
- Existing wallets (eSewa, Khalti) require full bank linkage
- Complex KYC excludes students and rural users
- High fees discourage small-value transfers
- No lightweight onboarding for merchants

## Slide 4: Product Demo

### Live Demonstration Flow

**1. Registration (30 seconds)**
- Enter phone number
- Verify OTP via email
- Set password
- Wallet automatically created

**2. Send Money (15 seconds)**
- Enter recipient phone or scan QR
- Enter amount (minimum NPR 10)
- Enter transaction PIN
- Instant confirmation

**3. Pay Bill (20 seconds)**
- Select provider (NTC, Ncell, NEA)
- Enter consumer number
- Confirm amount
- Pay with PIN

**4. Merchant Payment (10 seconds)**
- Customer scans merchant QR
- Enter amount
- Confirm with PIN
- Merchant receives instant notification

## Slide 7: Security Trust Layer

### Multi-Layer Security Architecture

```
Layer 1: Infrastructure
├── HTTPS/TLS 1.3
├── Web Application Firewall
├── DDoS protection
└── Security headers (CSP, HSTS)

Layer 2: Application
├── CSRF protection
├── SQL injection prevention
├── XSS filtering
├── Input validation
└── Session security

Layer 3: Transaction
├── Transaction PIN (bcrypt)
├── Fraud detection engine
├── Idempotency (no duplicates)
├── Replay attack prevention
└── Rate limiting

Layer 4: Operational
├── Audit logging
├── Real-time alerts
├── Automated backups
├── Incident response
└── Compliance monitoring
```
