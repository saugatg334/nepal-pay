═══════════════════════════════════════════════════════════════════════════════
                         ENCRYPTION IMPLEMENTATION
═══════════════════════════════════════════════════════════════════════════════

ALGORITHM:     AES-256-CBC
KEY DERIVATION: HKDF-SHA256 from APP_KEY
IV:            Random 16 bytes per token
STORAGE:       Base64-encoded ciphertext + IV
LOOKUP:        HMAC-SHA256 (one-way, irreversible)
ROTATION:      Built-in support for key rotation

DATABASE CHANGES:
  OLD: token VARCHAR(255) UNIQUE        → Plaintext (INSECURE)
  NEW: token_hash CHAR(64)              → HMAC for lookup
       token_encrypted TEXT             → AES-256-CBC encrypted
       token_iv VARCHAR(32)             → Initialization vector
